# Farmfinity | Agricultural E-Commerce Platform

Farmfinity is a web-based agricultural platform built with Django to simplify the purchase and management of farming products. It provides a user-friendly experience with dynamic AJAX interactions, product browsing, order processing, payment functionality, and feedback management.

**Features:** User Authentication | Product Management | Cart & Orders | Payments | Notifications | Feedback | AJAX

**Tech Stack:** Python, Django, HTML, CSS, JavaScript, AJAX, MySQL
